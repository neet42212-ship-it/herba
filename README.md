# HerbaGuard React + Vite

This repository contains the complete HerbaGuard website built with React and Vite.

## Project Overview
HerbaGuard is a herbal mosquito repellent concept featuring a smart packaging design, interactive label preview, and a modern UI.

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
The built site can be deployed to Netlify or any static hosting.
